# cartoon-reel-maker skill: কীভাবে ব্যবহার করবেন

1. এই zip টা unzip করবেন না।
2. Claude desktop: বাম পাশে Customize → উপরে Skills → ডান কোণায় Add → Upload skill → এই zip দিন → Upload।
3. পাশের switch টা চালু রাখুন।
4. Settings → Capabilities এ "Create and edit files" আর "Use the internet while making files" দুইটাই চালু রাখুন।
5. নতুন chat → plus → Skills → cartoon-reel-maker বাছাই করুন, তারপর গল্প বা voice mp3 দিন।
